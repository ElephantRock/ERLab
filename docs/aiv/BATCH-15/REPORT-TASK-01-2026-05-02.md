IMPLEMENTATION DETAILS
───────────────────────────────────────────────────────────

1. Cancel Button (AC-01)
   - Red "Cancel Run" Button (variant="destructive", size="sm") placed in the
     pipeline progress card header next to the status badges.
   - Visible only when: runId is set AND pipeline is not complete AND SSE is
     connected AND run has not been cancelled.
   - data-testid="cancel-run-btn" for test targeting.
   - Shows "Cancelling…" with disabled state while the API call is in flight.

2. Confirmation Dialog (AC-02, AR-01)
   - Fixed-position overlay (z-50) with semi-transparent backdrop.
   - Contains an AlertCircle icon, title "Cancel Pipeline Run?", explanatory
     text about stage preservation, and two buttons:
     - "No, Continue" (outline) — dismisses dialog
     - "Yes, Cancel Run" (destructive) — calls cancelRun(runId)
   - data-testid="cancel-confirm-dialog" for test targeting.
   - Error message displayed inline if cancelRun() fails.

3. Cancelled State & Partial Results (AC-03)
   - On successful cancellation, isCancelled flag is set.
   - Status badge switches from "Live" (blue) to "Cancelled" (red).
   - Cancel button is hidden (isRunning becomes false).
   - New CardContent section shows:
     - XCircle icon + "Pipeline run was cancelled" message
     - Count of completed stages: "N of M stage(s) completed before cancellation."
   - Results section shows for cancelled runs with "Pipeline Cancelled" heading
     and "No ideas were generated before cancellation." if no ideas exist.
   - handleReset clears all cancel state for re-runs.

4. State Variables Added
   - isCancelling: boolean — tracks in-flight cancel API call
   - isCancelled: boolean — set to true after successful cancellation
   - showCancelConfirm: boolean — controls confirmation dialog visibility
   - cancelError: string | null — error message if cancellation fails

5. Derived Values
   - isRunning: computed from runId, isComplete, isConnected, isCancelled
   - completedStages: stages filtered to status "completed"
   - hasPartialResults: isCancelled AND completedStages.length > 0
