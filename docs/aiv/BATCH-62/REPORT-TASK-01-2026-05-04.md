## Architecture

```
TreeSearchEngine
├── constructor(ideator: Ideator, scorer?: IdeaScorer, config?: TreeSearchConfig)
├── search(gaps, context_papers, initial_ideas?) → list[IdeaCandidate]
│   ├── _expand_node() → delegates to ideator.generate_ideas() [HB-01]
│   ├── _prune() → keeps top beam_width [HB-03 cap at 10]
│   └── _build_context() → formats gaps + papers for scoring
├── SimpleScorer (fallback: uses idea.overall_score)
├── BordaScorer (default: multi-dimension Borda count via borda_rank_graph_nodes)
└── TreeSearchConfig (beam_width, max_depth, ideas_per_node, recombination_rate)
```
