## TASK-01: `doom_loop.py` — Pure Detection Functions

### Public API

| Function | Signature | Purpose |
|----------|-----------|---------|
| `StageOutputSignature` | `@dataclass(frozen): stage_name, output_hash` | Hashable fingerprint of stage output |
| `hash_stage_output` | `(output: Any) -> str` | MD5-based canonical hash (12 hex chars) |
| `detect_identical_consecutive` | `(signatures, threshold=3) -> str \| None` | Detects N+ identical consecutive outputs |
| `detect_repeating_sequence` | `(signatures) -> list \| None` | Detects repeating patterns of length 2-5 |
| `check_pipeline_doom` | `(stage_history: list[dict]) -> str \| None` | High-level check combining both modes |

### Edge Cases Handled
- **None input** → hashes same as empty string
- **Non-serializable objects** → `str()` fallback
- **Empty list** → returns `None` (no doom)
- **Unicode content** → UTF-8 encoding, works correctly

## TASK-02: Orchestrator Wiring

### Changes to `orchestrator.py`

1. **`__init__`** (line ~189): Added `self._doom_history: list = []` and `self._doom_detected: bool = False`

2. **`run()`** (line ~1153): Reset both doom tracking variables at start of each run

3. **Stage loop** (after journal/Phase 7, before `_should_stop`):
   - Extracts fingerprint via `_extract_stage_fingerprint()`
   - Hashes and appends to `_doom_history`
   - Calls `check_pipeline_doom()` after each monitored stage
   - If doom detected: logs WARNING, sets `_doom_detected = True`
   - Skips remaining non-export stages with `status="skipped_by_doom"`
   - **Export stage always runs** even after doom detection

4. **Import**: Added `from backend.pipeline.monitoring.doom_loop import (StageOutputSignature, check_pipeline_doom, hash_stage_output)`
