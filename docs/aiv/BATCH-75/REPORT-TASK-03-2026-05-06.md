## Description

Fix EnsembleReviewResult serialization. The `synthesize()` method in `proposal_synthesizer.py` stored the raw Pydantic `EnsembleReviewResult` object into `proposal.sections["ensemble_review"]`, which caused `json.dumps()` to raise `TypeError: Object of type EnsembleReviewResult is not JSON serializable` when downstream code attempted serialization.

---

## Changes Made

### 1. `backend/pipeline/synthesis/proposal_synthesizer.py` (synthesize method, ~line 222)

**Before:**
```python
review_result = await self._ensemble_reviewer.review(proposal, idea)
proposal.sections["ensemble_review"] = review_result
```

**After:**
```python
review_result = await self._ensemble_reviewer.review(proposal, idea)
if review_result is not None:
    proposal.sections["ensemble_review"] = review_result.model_dump()
```

**Rationale:**
- `model_dump()` converts the Pydantic `EnsembleReviewResult` to a plain `dict`, which is JSON-serializable.
- The `None` guard prevents `AttributeError` if the reviewer returns `None` unexpectedly.
