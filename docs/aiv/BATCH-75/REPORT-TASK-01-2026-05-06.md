## Task Description

Add IdeaCandidate → ResearchIdea conversion in TreeSearchStage. The conversion
happens in `execute()` before `ctx.result.ideas` assignment. A static method
`_convert_to_research_ideas()` handles field mapping with safe defaults for
fields that IdeaCandidate lacks (`domain`, `round_generated`, `supporting_papers`,
`source_gap_ids`).

Additionally (per Lead Response to Reviewer flags CHK-16/CHK-17): update
`_build_tree_data()` to use `getattr()` guards for `idea.id` and
`idea.parent_idea_ids`, since ResearchIdea lacks both fields.

## Implementation Details

### 1. `_convert_to_research_ideas()` static method (AC-01-01, AC-01-02)

Added as a `@staticmethod` on `TreeSearchStage`. Maps all IdeaCandidate fields
to ResearchIdea equivalents:

| Source (IdeaCandidate)     | Target (ResearchIdea)     | Default       |
|----------------------------|---------------------------|---------------|
| `title`                    | `title`                   | —             |
| `problem_statement`        | `problem_statement`       | —             |
| `proposed_method`          | `proposed_method`         | —             |
| `expected_contributions`   | `expected_contributions`  | `""`          |
| `novelty_rationale`        | `novelty_rationale`       | `""`          |
| `evaluation_approach`      | `evaluation_approach`     | `""`          |
| `overall_score`            | `score`                   | `0.0`         |
| `parent_idea_ids`          | `source_gap_ids`          | `[]`          |
| —                          | `domain`                  | `"AI/NLP"`    |
| —                          | `round_generated`         | `1`           |
| —                          | `supporting_papers`       | `[]`          |

All optional field accesses use `getattr()` with safe defaults. Empty string
and `None` values for text fields are coerced to `""`. `None` for
`parent_idea_ids` is coerced to `[]`.

### 2. `execute()` isinstance assertion (AC-01-03, HB-01)

After calling `_convert_to_research_ideas()`, `execute()` asserts:

```python
assert all(isinstance(i, ResearchIdea) for i in ideas), (
    "HB-01 violation: TreeSearchStage must assign only ResearchIdea to ctx.result.ideas"
)
```

This satisfies HB-01 and makes any future conversion breakage immediately visible.

### 3. `_build_tree_data()` getattr guards (AC-01-04, CHK-16/CHK-17)

Updated `idea.id` → `getattr(idea, 'id', idea.title[:60])` and
`idea.parent_idea_ids` → `getattr(idea, 'parent_idea_ids', getattr(idea, 'source_gap_ids', []))`.
Also updated `overall_score` → `getattr(idea, 'overall_score', getattr(idea, 'score', 0.0))`
for the score field. These guards allow `_build_tree_data()` to work with both
IdeaCandidate and ResearchIdea objects.

### 4. Import addition

Added `from backend.pipeline.generation.models import ResearchIdea` at module
top level (line 15) as a runtime import (not under `TYPE_CHECKING`), since it
is used for `isinstance()` checks and `ResearchIdea()` construction.
