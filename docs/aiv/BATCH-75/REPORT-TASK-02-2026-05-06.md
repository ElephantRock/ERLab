§5.2  TASK DESCRIPTION
───────────────────────────────────────────────────────────

Harden persist_ideas() to accept IdeaCandidate-like objects with getattr()
guards for .domain, .source_gap_ids, .expected_contributions, and
.novelty_rationale. Add dedup check before crud.create_idea() to prevent
duplicate (title, pipeline_run_id) rows.

───────────────────────────────────────────────────────────
CHANGES MADE
───────────────────────────────────────────────────────────

1. backend/pipeline/persistence.py — persist_ideas() method (+26 LOC)

   a) Added imports: `select` from sqlalchemy, `Idea as IdeaModel` from
      backend.db.models — used for the dedup query.

   b) Dedup check (HB-03): Before calling crud.create_idea(), a SELECT
      query checks for an existing Idea row with the same (title,
      pipeline_run_id). If found, the idea is skipped with an info-level
      log message and `continue`.

   c) getattr() guards (HB-02):
      - `idea.domain`          → `getattr(idea, 'domain', 'AI/NLP')`
      - `idea.source_gap_ids`  → `getattr(idea, 'source_gap_ids', None)`
      - `idea.expected_contributions` → `getattr(idea, 'expected_contributions', '')`
      - `getattr(idea, 'novelty_rationale', '')` — guarded even though not
        persisted yet, preventing future AttributeError if the field is
        accessed downstream.

   d) source_gap_ids serialization uses the getattr result; if None, no
      json.dumps() is attempted — stored as NULL.

   e) No changes to persist_proposals() or any other method.
