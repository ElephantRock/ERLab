## Design Decisions

1. **Async `generate()`**: Made the public API async to accommodate LLM provider calls (`await provider.complete()`). Template path is synchronous internally but wrapped in async for consistent interface.

2. **Template-only mode**: The `_generate_template()` method produces complete, executable Python scripts without any LLM dependency. This is the default path when no provider is configured.

3. **LLM mode**: When a provider is supplied, `_generate_with_llm()` prompts the LLM with structured instructions and strips markdown code fences from the response.

4. **`_escape_brackets()` helper**: Since the template uses f-strings internally, curly braces in user-provided text are escaped to prevent `KeyError` during string formatting.

5. **Mock IdeaCandidate**: Tests create a fully-populated `IdeaCandidate` with realistic research content (RAG + cross-attention fusion topic).
