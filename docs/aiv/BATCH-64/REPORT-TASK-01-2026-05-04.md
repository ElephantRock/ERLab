## Design Decisions

1. **Duck-typed inputs** — metrics accept `Any` with `getattr()` access, compatible with existing `IdeaCandidate`, `ResearchIdea`, `Paper`, and `ResearchGap` models without import coupling.
2. **`_word_overlap_similarity`** uses Jaccard index (token intersection / union) with stop-word filtering as a lightweight proxy — no embeddings needed per spec.
3. **`_count_concrete_claims`** uses 10 regex patterns (numbered items, "we will", "using X", "-based/-driven", quantitative claims, action verbs, "our method", "specifically", "baseline") — each pattern matched at most once, capped at 10.
4. **`compute_all()`** falls back to `supporting_papers` for `prior_art_distance` when `closest_papers` is not supplied.
