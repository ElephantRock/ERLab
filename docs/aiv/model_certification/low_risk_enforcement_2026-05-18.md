## 9. Enforcement Mechanism

### Gateway Call Flow (enforce mode)

1. SmartRouter routes all stages (get RoutingDecision)
2. Check: is `request.stage` in `enforced_stages`?
   - **Yes**: `enforcement_applied = True`
     - If decision is degraded → return degraded LLMResponse immediately
     - If decision is valid → proceed with certified model
   - **No**: `enforcement_applied = False`
     - Log as DRY-RUN, execute via legacy provider

### Log Fields Added

- `enforcement_applied`: bool
- `certification_status`: "certified" | "no_certified_candidate" | "unknown"
- `stage_eligibility`: from routing decision
- `hard_gate_failures`: from routing decision warnings
