IMPLEMENTATION SUMMARY
═══════════════════════════════════════════════════════════════════

Added an inline results section to the pipeline-new page that appears
after pipeline completion, showing generated ideas with scores,
summary stats, and navigation links.

FILES MODIFIED
───────────────────────────────────────────────────────────────────

1. frontend/src/api/pipeline.ts (MODIFY)
   - Added `getRunIdeas(runId: number)` function that calls
     `GET /pipeline/runs/{runId}/ideas` and returns
     `Promise<{ ideas: IdeaSummary[]; total: number }>`.
   - Added `IdeaSummary` to type imports.

2. frontend/src/pages/pipeline-new.tsx (MODIFY)
   - Added state: `ideas`, `ideasError`, `ideasLoading`.
   - Added `useEffect` hook that triggers on `isComplete` change to
     fetch ideas from the latest run via `listRuns` + `getRunIdeas`.
   - Added inline results section (`data-testid="pipeline-results"`)
     that shows:
     - "Pipeline Complete" banner with idea count summary
     - Idea cards with title, domain, and overall score badge
     - Each idea card is clickable → navigates to `/ideas/:id`
     - Error display when ideas fetch fails (`data-testid="ideas-error"`)
     - "View All Ideas" button (`data-testid="view-all-ideas"`)
     - "Run Another" button (`data-testid="run-another"`) that resets form state
   - Added `useNavigate` for navigation and `handleReset` for form reset.

3. frontend/src/pages/__tests__/pipeline-results.test.tsx (NEW)
   - 6 tests (TEST-12-02-01 through 06).
   - Uses controlled `mockIsComplete` variable to simulate pipeline
     completion state transitions.
