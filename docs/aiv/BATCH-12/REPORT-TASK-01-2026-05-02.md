IMPLEMENTATION SUMMARY
═══════════════════════════════════════════════════════════════════

Added a new read-only endpoint `GET /api/v1/pipeline/runs/{run_id}/ideas`
that returns all ideas generated by a specific pipeline run.

FILES MODIFIED
───────────────────────────────────────────────────────────────────

1. backend/db/crud.py (MODIFY)
   - Added `get_ideas_for_run(session, run_id)` — queries ideas by
     `pipeline_run_id` FK, ordered by `id` ascending.
   - Added `count_ideas_for_run(session, run_id)` — returns total count
     of ideas for a run via `func.count()`.

2. backend/api/routes/pipeline.py (MODIFY)
   - Added `GET /runs/{run_id}/ideas` route handler `get_run_ideas()`.
   - Validates run exists (404 if not via `NotFoundError`).
   - Returns `{ "ideas": [...], "total": int }` with full idea fields:
     id, title, problem_statement, proposed_method, expected_contributions,
     domain, novelty_score, feasibility_score, overall_score, created_at.
   - Read-only: GET only. POST/PUT/PATCH return 405.

3. backend/tests/test_api/test_run_ideas.py (NEW)
   - 6 tests (TEST-12-01-01 through 06).
