FILES MODIFIED

1. frontend/src/pages/run-detail.tsx (NEW)
   - Full page component using `useParams` to get run ID.
   - Uses `useQuery` (react-query) to fetch run details via
     `getRunDetail(id)` and ideas via `getRunIdeas(id)`.
   - Renders:
     - Back button → navigates to `/`
     - Run title with status badge
     - Metadata card: ID, domain, created_at, completed_at
     - Stages timeline: all 8 PIPELINE_STAGES with completed/current/pending
       indicators (CheckCircle2, Loader2, Circle icons)
     - Error card (failed runs): shows error_message prominently
     - Resume button (failed runs only): `data-testid="resume-btn"`
     - Ideas list: clickable idea cards with title, domain, score badge
     - Duration card: computed from created_at → completed_at
   - Error state: shows "Run not found" when API returns error

2. frontend/src/App.tsx (MODIFY)
   - Added import for `RunDetailPage` from `./pages/run-detail`.
   - Added `<Route path="/runs/:id" element={<RunDetailPage />} />`.

3. frontend/src/pages/dashboard.tsx (MODIFY)
   - Changed RunCard rendering to pass `onClick={() => navigate(`/runs/${run.id}`)}`
     so clicking a run card navigates to the detail page.
