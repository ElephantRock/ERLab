Added optional fields:

### 2. `frontend/src/api/gaps.ts` — Extended listGaps params

Added query params: `search`, `gap_type`, `min_confidence`, `sort_by`, `sort_order`. All are optional and only appended to URLSearchParams when non-empty.

### 3. `frontend/src/pages/gaps-explorer.tsx` — Added search/filter/sort controls

New state variables: `searchText`, `gapTypeFilter`, `sortBy`, `minConfidence`

Controls added (mirroring Ideas Browser pattern):
- **Search input** — text input with search icon, debounced via `useMemo`
- **Gap type select** — "All Types" + 4 gap types (methodological, empirical, theoretical, cross-domain)
- **Min confidence slider** — 0–1, step 0.1, with label showing current value
- **Sort dropdown** — Confidence, Date, Type options
- **Reset button** — clears all filters, shown only when filters are active

Additional changes:
- Removed client-side `.sort()` (server now handles sorting)
- Changed "N gaps identified" → "N gaps found" to match API total (HB-03)
- Empty state message shows search query when applicable
