## Changes Made

### 1. `backend/db/crud.py` — Added `search_gaps()` and `count_search_gaps()`

- **`search_gaps()`** — New function supporting:
  - `run_id` — filter by pipeline run
  - `search` — case-insensitive `ilike` on title AND description
  - `gap_type` — exact match, validated against whitelist `{methodological, empirical, theoretical, cross-domain}`
  - `min_confidence` — >= filter
  - `sort_by` — column selection via whitelist `{confidence, date, type}` (AR-01)
  - `sort_order` — `asc`/`desc`
  - `limit`/`offset` — pagination
- **`count_search_gaps()`** — Matching count function for same filters
- Defined `VALID_GAP_SORT_COLUMNS` and `VALID_GAP_TYPES` constants

### 2. `backend/api/routes/gaps.py` — Updated `list_gaps` route

- Added query params: `search`, `gap_type`, `min_confidence`, `sort_by`, `sort_order`
- Validates `sort_by` against `{confidence, date, type}` whitelist (AR-01)
- Validates `gap_type` against `{methodological, empirical, theoretical, cross-domain}` (AR-02)
- Response now includes `truth` and `related_clusters` fields per gap (BATCH-38 scope)
- Helper functions `_build_truth()` and `_build_related_clusters()` for response serialization
