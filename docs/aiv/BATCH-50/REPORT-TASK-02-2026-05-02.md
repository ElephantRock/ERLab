## Architecture

### Backend
- `ConnectionManager`: Channel-based subscription management with connect/disconnect/broadcast
- WebSocket endpoint at `/ws`: JSON-based protocol with `subscribe`, `ping` actions
- Pipeline progress wired to broadcast on `pipeline:{run_id}` channels
- Config-gated: `websocket_enabled=False` rejects connections with code 1008

### Frontend
- `useWebSocket` hook: Auto-connects, subscribes to channel, auto-reconnects with exponential backoff
- Message buffer (last 100 messages) and `onMessage` callback support
