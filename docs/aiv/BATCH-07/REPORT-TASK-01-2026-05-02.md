## Implementation Summary

### 1. Interactive Wizard (`backend/cli/commands/setup.py`)

Created a full-featured `erock setup` CLI wizard with the following stages:

1. **Python Version Detection** — Checks for Python ≥ 3.11. Exits with an error panel if incompatible.
2. **Provider Selection** — Offers OpenAI / Anthropic / Gemini / Ollama via interactive prompt or `--provider` flag.
3. **API Key Validation** — Makes a real HTTP call to the chosen provider's endpoint:
   - OpenAI: `GET /v1/models` with Bearer token
   - Anthropic: `POST /v1/messages` with `x-api-key` header
   - Gemini: `GET /v1beta/models?key=...`
   - Ollama: No key required
4. **Ollama Detection** — Probes `localhost:11434/api/tags` to confirm Ollama is running.
5. **`.env` Generation** — Iterates all fields from the `Settings` class (AR-01 compliance) and writes a complete `.env` file with sensible defaults aligned to the chosen provider (embedding model, model name, etc.).
6. **Optional Test Pipeline** — Offers to run a single-idea pipeline to verify end-to-end functionality.
7. **Next Steps** — Prints a rich panel with commands to get started.
