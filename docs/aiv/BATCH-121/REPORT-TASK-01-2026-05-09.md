## Implementation Details

- **ClaimType**: `Enum` with exactly 5 members: `METHOD`, `RESULT`, `LIMITATION`, `FUTURE_WORK`, `COMPARISON`
- **Claim**: `@dataclass` with all fields from the Blueprint schema:
  - Required: `claim_type`, `title`, `description`, `source_paper_id`
  - Auto-generated: `claim_id` (UUID via `uuid.uuid4().hex`)
  - Identity: `source_section` (default `"abstract"`), `confidence` (default `0.5`)
  - METHOD-specific: `method_name`, `method_category`, `constraints` (all default `None`)
  - RESULT-specific: `dataset`, `metric`, `value`, `baseline_method`, `baseline_value` (all default `None`)
  - LIMITATION-specific: `limitation_category`, `acknowledged` (all default `None`)
  - FUTURE_WORK-specific: `feasibility`, `potential_impact` (all default `None`)
  - COMPARISON-specific: `compared_to`, `relationship` (all default `None`)
