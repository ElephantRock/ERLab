## Implementation Details

### Gold-Standard Papers
Five synthetic paper abstracts spanning diverse NLP topics:
1. **2301.00001** — RAG-Fusion (retrieval-augmented generation)
2. **2301.00002** — ConTra (contrastive learning)
3. **2301.00003** — SafeGuard (safety filtering)
4. **2301.00004** — SparseRetriever (scaling laws)
5. **2301.00005** — MedSum (medical summarization)

### Test Approach
- Uses `_FakeProvider` with pre-defined realistic claims covering all 5 ClaimTypes
- Tests use `asyncio.run()` directly (project convention: `-p no:asyncio`)
- Helper `_extract_all_claims()` extracts from all 5 papers and aggregates results
