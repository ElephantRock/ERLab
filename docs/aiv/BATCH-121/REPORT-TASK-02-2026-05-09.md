## Description

Create ClaimExtractor class that uses `provider.structured_output()` to extract typed Claims from paper text. Includes claim extraction prompt template with closed-book policy. Implements hard boundaries HB-01 (no crash on failure) and HB-02 (all claims have source_paper_id).

## Implementation Details

### ClaimExtractor
- `__init__(self, provider: LLMProvider)` — validates provider is `LLMProvider` instance (raises `TypeError` otherwise)
- `async extract(paper_text, paper_id, wiki=None) -> list[Claim]` — extracts claims via `structured_output`
- `async extract_batch(papers: list[dict]) -> dict[str, list[Claim]]` — batch extraction mapping paper_id → claims

### Hard Boundaries
- **HB-01**: `extract()` catches all exceptions, returns `[]`, logs warning via `logging.warning()`
- **HB-02**: Every Claim gets `source_paper_id` from the `paper_id` parameter; enforced in `_parse_claim()` and post-extraction check

### Prompt Template
- Located at `backend/pipeline/claims/prompts/claim_extraction.md`
- Contains explicit **CLOSED-BOOK POLICY** instruction
- Specifies all 5 claim types with descriptions
- Documents all field rules (type-specific field filling, confidence range, value formatting)
- Uses `{paper_text}` and `{wiki_section}` template placeholders

### JSON Schema
- Defined in `_CLAIM_SCHEMA` constant
- Requires `claims` array with `claim_type`, `title`, `description` as required fields
- All type-specific fields are optional (`string | null`)
