## Hard Boundary Compliance

- **HB-01**: All queries use SQLAlchemy parameterized bindings. The `search`
  param uses `Idea.title.ilike(f"%{search}%")` where `search` is a bound
  parameter, never interpolated into raw SQL. SQL injection test confirms
  injection attempts are treated as literal strings.
- **HB-02**: No scoring algorithms were altered. Only display and sorting of
  existing scores.

## Design Decisions

1. **source_gap_ids as JSON Text**: Stores a JSON array of gap title strings.
   Historical ideas have `NULL` source_gap_ids (acceptable per v1.1).
2. **count_ideas_for_gap**: Uses parameterized LIKE on `source_gap_ids` column
   to match gap titles within the JSON blob. No junction table needed.
3. **Nulls-last sorting**: Uses SQLAlchemy `case()` expression to push NULL
   scores to the end of results regardless of sort direction.
4. **effective_min_score**: The route converts `min_score=0.0` (default) to
   `None` so the filter is only applied when the user explicitly sets it.
