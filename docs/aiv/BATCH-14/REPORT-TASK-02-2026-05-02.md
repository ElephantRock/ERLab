## Design Decisions

1. **Radix UI Slider & Select**: Used standard shadcn/ui patterns for the
   slider and select components. Installed `@radix-ui/react-slider` as a new
   dependency.
2. **Search input replaces domain filter**: The original Ideas Browser had only
   a domain filter. Now it has a dedicated search input plus domain filter,
   sort dropdown, and min score slider — all additive and server-side (AR-01).
3. **GapCard click navigation**: Clicking the "N ideas" badge navigates to
   `/ideas?search=<gap_title>`, leveraging the new backend search param for
   client-side gap→idea traceability.
4. **Source Gaps on Idea Detail**: Rendered as a simple list with amber dots
   when `source_gap_ids` is present and non-empty.
5. **jsdom polyfills**: Added class-based ResizeObserver/IntersectionObserver
   mocks to the existing ideas-browser test to support the new Slider component.
