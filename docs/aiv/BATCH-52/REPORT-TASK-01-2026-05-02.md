## Objective

## Changes Made

### 1. Dependencies
- Added `jest-axe` (dev dependency) for accessibility rule checking

### 2. New Files
| File | Description |
|------|-------------|
| `frontend/src/test/a11y-test-utils.ts` | Shared `checkA11y()` utility wrapping jest-axe with color-contrast disabled (jsdom limitation) |
| `frontend/src/pages/__tests__/a11y.test.tsx` | 6 a11y tests for Dashboard, Ideas Browser, Gaps Explorer, Settings, Login, Knowledge Search |

### 3. Accessibility Violations Found & Fixed

| Violation | Location | Fix |
|-----------|----------|-----|
| `heading-order` (h1→h3 skipping h2) | `card.tsx` CardTitle renders as `<h3>` | Changed CardTitle from `<h3>` to `<h2>` globally |
| `aria-prohibited-attr` (aria-label on span without role) | `settings.tsx` connection dot | Added `role="status"` to the span element |
| `aria-input-field-name` (Slider thumb missing accessible name) | `slider.tsx` Radix Slider thumb | Forwarded `aria-label` prop from Slider root to Thumb |

### 4. Test Results
- **6 a11y tests**, all passing
- Color-contrast disabled in jsdom (no real CSS computed styles)
- All 337 frontend tests pass (70 test files)
