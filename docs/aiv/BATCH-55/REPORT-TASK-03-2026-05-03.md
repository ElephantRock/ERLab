# BATCH-55 TASK-03: Add Frontend Stale Run Detector

**Date**: 2026-05-03
**Status**: DONE

## Problem

Users had no indication when a pipeline run might have stalled. Runs stuck in "running" status for extended periods showed no warning, leading to confusion about whether the run was still progressing or had failed silently.

## Changes

### `frontend/src/pages/run-detail.tsx`

1. **Added React imports** — Added `useMemo`, `useState`, and `useEffect` from React.

2. **Added stale detection logic**:
   - `now` state variable updated every 30 seconds while run is in "running" status
   - `isStale` memoized value returns `true` when a run has been running for over 5 minutes
   - `useEffect` sets up a 30-second interval to re-evaluate staleness

3. **Added stale run warning banner** — Yellow warning banner with `AlertTriangle` icon appears before the metadata card when `isStale` is true. Uses `data-testid="stale-run-warning"` for testing.

### `frontend/src/components/pipeline/run-card.tsx`

4. **Added stale run indicator in dashboard** — Added `AlertTriangle` icon next to stale runs in the run list on the dashboard. Uses `isStaleRun()` helper that checks if a running run was created more than 5 minutes ago. Uses `data-testid="stale-run-icon"` for testing.

## Tests

Created `frontend/src/pages/__tests__/batch55-stale-run.test.tsx` with 2 tests:
- `TEST-55-03-01` — Shows warning for run in "running" status older than 5 minutes
- `TEST-55-03-02` — Does not show warning for completed runs

All tests pass (339 frontend tests total).
