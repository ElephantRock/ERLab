**Objective:** Create `backend/pipeline/evaluation/plan_generator.py` with `EvaluationPlanGenerator` class. Template mode generates structured evaluation plan from proposal method text.

**Verified Present:**
- `EvaluationPlanGenerator` class with:

  - `_generate_template(idea: dict) -> EvaluationPlan` — template mode (no LLM)
  - `_generate_with_llm(idea: dict) -> EvaluationPlan` — LLM mode

- `EvaluationPlan` dataclass with fields: `idea_id`, `title`, `datasets`, `baselines`, `metrics`, `ablations`
- Supporting dataclasses: `DatasetRecommendation`, `BaselineMethod`, `MetricTarget`, `AblationExperiment`
- Template mode produces: 3 datasets, 3 baselines, 4 metrics, 3 ablations
- Does NOT require LLM provider (template mode default)
- Does NOT modify proposal synthesizer
