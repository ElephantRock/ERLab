### TASK-02: RadarChart Component ✅
**Files Created:**
- `frontend/src/components/ideas/radar-chart.tsx` — Pure SVG radar/spider chart (152 lines)

**Key Implementation Details:**
- Zero external dependencies (HB-04) — uses only SVG polygon, line, circle, text
- Props: `data: Array<{label: string, value: number}>`, `size?: number` (default 200), `color?: string`
- 4 grid rings at 0.25/0.5/0.75/1.0, axis lines, data polygon with vertex dots
- Color-coded by average score: green ≥0.8, yellow ≥0.6, orange ≥0.4, red <0.4
- CSS class applied for testability: `radar-color-green`, `radar-color-yellow`, etc.
- `data-testid="radar-chart"` on SVG, `data-testid="radar-polygon"` on data polygon, `data-testid="radar-label-N"` on labels
- Responsive sizing via `viewBox` matching width/height
