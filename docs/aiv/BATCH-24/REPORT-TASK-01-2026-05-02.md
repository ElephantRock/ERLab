## Implementation Details

### POST /knowledge/ingest
- Accepts multipart/form-data with a `file` field
- **HB-01**: Validates PDF magic bytes (`%PDF`) before any processing — rejects executables, text files, and other non-PDF uploads with 400 Bad Request
- Returns 422 when no file is provided
- Parses PDF via `PDFService`, chunks with section-aware chunker, embeds via `EmbeddingService`, stores in ChromaDB via `VectorStore`
- Uses tempfile + cleanup in `finally` block for safe file handling
- Returns `{status, filename, chunks}` response

### Enhanced GET /knowledge/stats
- Returns original fields: `chroma_persist_dir`, `embedding_provider`, `embedding_model`
- New enriched fields:
  - `total_chunks` — from `VectorStore.get_stats().document_count`
  - `total_documents` — computed by counting unique `paper_id` values from collection metadata
- Gracefully falls back to 0 values when ChromaDB is not installed
