## Implementation Details

### UploadZone Component
- Drag-and-drop area with click-to-upload fallback
- States: `idle` → `uploading` → `success` / `error`
- Client-side `.pdf` extension validation (complements HB-01 server-side magic-bytes check)
- Shows loading spinner with progress bar during upload
- Shows success confirmation with chunk count after ingestion
- Shows error message with retry option
- `onUploadSuccess` callback to refresh stats

### Stats Banner (in KnowledgeSearch)
- Two stat cards: Documents (total_documents) and Chunks (total_chunks)
- Auto-fetched via `@tanstack/react-query` with `knowledge-stats` key
- Refreshed automatically after successful upload via `queryClient.invalidateQueries()`
- Hidden until stats data is available

### API Client
- `getKnowledgeStats()` — GET /knowledge/stats → `KnowledgeStats`
- `ingestPdf(file)` — POST /knowledge/ingest with FormData (bypasses JSON content-type)
