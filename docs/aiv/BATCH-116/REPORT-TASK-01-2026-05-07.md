## §5.2.11 — Adaptations

1. **4 domains instead of minimum 3:** The BLUEPRINT required "3+ domains." Implementation provides 4 (AI/NLP, AI/Reasoning, Biomedical, Computer Science) with 8 gaps each — exceeding the minimum and providing broader coverage for future domain routing.
2. **`get_gold_gaps()` helper with fallback:** Added a `get_gold_gaps(domain)` function beyond the bare `GOLD_STANDARD_GAPS` dict. This provides exact match → prefix match → AI/NLP fallback, making the orchestrator's domain resolution more robust without changing external interfaces.
3. **Verification-module `PipelineEvaluator` reuse:** The `_evaluate_pipeline` method instantiates `PipelineEvaluator` from `backend/pipeline/verification/pipeline_evaluator.py` (not the `evaluation/` subsystem's evaluator). This separation ensures the quality-evaluation path is independent of per-idea evaluation scoring.
