## TASK-02: RelevanceFilter Integration (5 tests) ✅

### Changes

1. **SearchService.__init__** — Added optional `embedding_provider: Any | None = None` parameter
2. **search_all()** — After deduplication, if embedding_provider is set:
   - Creates a `RelevanceFilter` with the provider
   - Runs `relevance_filter.filter(all_results, query)` (async)
   - Logs filter stats: `"{pre_count} → {post_count} papers"`
   - On exception: logs warning and returns unfiltered (deduped) results
3. **RelevanceFilter not modified** — Uses existing class as-is

## TASK-03: Health Check + MultiSource Wiring (5 tests) ✅

### Changes

1. **SearchService.health_check()** — New async method:
   - Iterates all registered sources concurrently (`asyncio.gather`)
   - For each source: runs `source.search("test", limit=1)` with configurable timeout (default 5.0s)
   - Returns `dict[str, {"healthy": bool, "latency_ms": float}]`
   - Failed/timed-out sources marked as `healthy=False`
   - Latency measured with `time.monotonic()`

2. **MultiSourceSearcher** — Not modified (already supports N sources; verified via test)
