## Implementation Notes

1. **Coloured prefixes:** `[BACKEND]` in ANSI blue (\033[94m), `[FRONTEND]` in ANSI green (\033[92m), streamed via daemon threads using `io.TextIOWrapper`.
2. **Process cleanup order:** Backend first, then frontend. Uses `terminate()` → `wait(5s)` → `kill()` escalation.
3. **`stop_event`** (threading.Event) initialised before the try block to avoid `NameError` in the finally block on early exceptions.
4. **E2E test** requires explicit `EROCK_E2E=1` to avoid CI/test-suite hangs from real server startup.
