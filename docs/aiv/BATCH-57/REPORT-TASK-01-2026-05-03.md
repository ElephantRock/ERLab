# BATCH-57 TASK-01: Fix DB Schema Sync

**Date:** 2026-05-03
**Status:** ✅ COMPLETE

## Problem

SQLite database created with `create_all()` does not reflect columns added to SQLAlchemy models in later batches. Running `init_db()` only creates missing tables — it never alters existing tables to add new columns.

## Changes

### `backend/db/database.py`

1. Added `import logging` and `logger = logging.getLogger(__name__)` at module level.
2. Added `ensure_schema_sync(engine)` function that:
   - Uses SQLAlchemy `inspect()` to compare model columns against actual DB columns
   - Issues `ALTER TABLE ... ADD COLUMN` for any missing columns
   - Logs each migration at INFO level
   - Safe to run repeatedly (idempotent)
3. Updated `init_db()` to call `ensure_schema_sync(engine)` after `create_all()`.

### `backend/tests/test_db/test_batch57_task01.py`

- `test_57_01_01_ensure_schema_sync_adds_missing_columns` — verifies function runs without error on fresh DB
- `test_57_01_02_ensure_schema_sync_idempotent` — verifies double-invocation is safe
