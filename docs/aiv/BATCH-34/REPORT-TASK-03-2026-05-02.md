### Commands (`backend/cli/commands/research.py` — NEW)
Registered as `erock research` subcommands via Typer sub-app.

| Command | Description |
|---|---|
| `erock research open {id}` | Open idea in browser (configurable base URL) |
| `erock research proposal {id}` | Generate proposal via LLM (markdown/latex format) |
| `erock research export {id}` | Export idea to file (markdown or JSON format) |

**Details:**
- `open`: Uses `webbrowser.open()` with configurable `--url` flag (default: localhost:5173).
- `proposal`: Invokes `ProposalSynthesizer` via `_run_async` helper; displays result in Rich panel.
- `export`: Writes markdown (with sections) or JSON (structured data) to a configurable `--output` path.
