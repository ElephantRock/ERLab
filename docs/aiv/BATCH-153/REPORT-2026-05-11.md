## Task-by-Task Implementation

### TASK-01: PaperSynthesizer Class ✅

- Created `PaperSynthesisResult` dataclass with 6 fields: `proposal_id`, `paper_markdown`, `word_count`, `venue`, `model_used`, `source_count`
- `PaperSynthesizer.synthesize()` accepts proposal text + source papers + domain, returns `PaperSynthesisResult | None`
- Uses generation provider (A-01) via injected `LLMProvider`
- Returns `None` on LLM failure (HB-02)
- `[SOURCE-X]` citation policy enforced in prompt (HB-04)
- Word count computed accurately from LLM output

### TASK-02: PaperSynthesisStage + Venue Templates ✅

- Added `PaperSynthesisStage` to `stages.py` following exact `AdversarialReviewStage` pattern
  - Uses `_get_metadata()` / `_set_metadata()` static methods
  - For each proposal, runs `PaperSynthesizer` with formatted source papers
  - Stores result in `proposal.metadata["full_paper"]` as dict
  - Gracefully handles all exceptions (HB-02)
  - Skips when strategy flag disabled
- Added `paper_synthesis` to `_STAGE_ORDER` at position 9 (after `adversarial_review`, before `proposal_deepening`)
- Created `venue_templates.py` with 4 presets: IEEE (`IEEEtran`), ACM (`acmart`), NeurIPS (`neurips_2026`), Generic (`article`)
- Updated `presets.py`: `_all_stages_enabled()` now lists 12 stages; docstring updated

### TASK-03: LatexExporter + API Route ✅

- Extended `LatexExporter.export()` with optional `venue` parameter
  - When `venue` provided: uses venue template preamble + converts full paper markdown to LaTeX body
  - When `venue` is `None`: uses existing generic TEMPLATE (backward compatible)
- Added `GET /api/export/latex/{run_id}?venue=generic` to export routes
  - Uses `/api/export/` prefix (FLAG-03 correction from Lead Response)
  - Returns `.tex` as `text/x-latex`
  - Handles proposals as `ResearchProposal`, dict, or generic object
- Fixed unused `HTTPHeader` import in `export.py`

### TASK-04: Strategy Presets ✅

- `deep_research`: `paper_synthesis=enabled`
- `academic_proposal`: `paper_synthesis=enabled` (with 900s timeout)
- `fast_scan`: `paper_synthesis=disabled`
- `literature_review`: `paper_synthesis=disabled` (FLAG-02)
- All 4 presets load without error (TEST-153-04-04)
